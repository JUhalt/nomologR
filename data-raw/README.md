# nomologR example-data strategy

Public example datasets are **simulated from known population models**, not
copied from proprietary or substantive research datasets.

## Why simulate?

A known generating model lets learners and the test suite ask whether
`nomologR` recovers features that are actually known:

- number of factors,
- primary loadings,
- factor correlation,
- intentionally weak items,
- an intentional cross-loading item,
- a known structural/nomological network,
- a known source of measurement non-invariance.

This turns each demonstration dataset into both a teaching resource and a
statistical regression test (`tests/testthat/test-nomo-data.R`).

## Datasets

All three datasets are generated by `data-raw/nomo_demo.R` and documented in
`R/data.R`.

### `nomo_demo_continuous`

500 cases; two factors correlated .40; five candidate indicators per factor on a
continuous rating metric. Teaching features:

- `a5` cross-loads (.45 on A, .35 on B);
- `b5` is weak (.30 on B);
- MCAR missingness in `a2` (15 cases) and `b3` (12 cases).

### `nomo_demo_ordinal`

The same latent responses as `nomo_demo_continuous` (before missingness),
thresholded into five ordered categories at -1.80, -0.80, 0.20, and 1.20. No
missing values. Supports polychoric, WLSMV, and ordinal-reliability workflows.

### `nomo_demo_network`

800 cases in two administration groups (`online`, `paper`; 400 each). Agency
(`ag1`–`ag4`), Persistence (`pe1`–`pe4`), and Social desirability (`sd1`–`sd3`)
indicators plus an observed `Performance` outcome. Within-group structural
model: Persistence ~ .45 Agency; Performance ~ .40 Agency + 0 Persistence;
Agency and Social desirability uncorrelated. Invariance features: equal
loadings, latent Agency mean .25 SD higher in `paper`, and the `ag3` intercept
.50 higher in `paper`.

## Reproducibility rules

1. Generation code lives in `data-raw/`.
2. Fixed seeds and the random-number generator kind are recorded in the
   generation script.
3. Population parameters are documented alongside the script and in `R/data.R`.
4. Unit tests may use smaller runtime-generated fixtures, but the public example
   data should be stable across package versions unless NEWS documents a change.
5. The dissertation Religiosity/Spirituality data may later be used in a vignette
   only if a public/reusable source and clear data provenance are established;
   the core package tests must not depend on those substantive data.
