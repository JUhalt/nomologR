# Plot exploratory factor-analysis evidence

Plot exploratory factor-analysis evidence

## Usage

``` r
# S3 method for class 'nomo_efa'
plot(x, type = c("pattern", "items", "residuals", "factor_correlations"), ...)
```

## Arguments

- x:

  A `nomo_efa` object.

- type:

  Plot type: `"pattern"`, `"items"`, `"residuals"`, or
  `"factor_correlations"`.

- ...:

  Unused.

## Value

A `ggplot2` object.
